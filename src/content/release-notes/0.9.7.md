## New Shortcut Behavior

Silkey includes the **Auto** shortcut mode from Handy v0.9.7, so the same shortcut can work as both push-to-talk and a toggle. It is the default for new installs.

- **Auto** — Hold to record and release to stop, or tap once to start and tap again to stop.
- **Hold** — Records only while you hold the shortcut. This is the old push-to-talk behavior.
- **Toggle** — Tap once to start recording and tap again to stop.

Existing users will keep their current shortcut behavior after updating. To try Auto, go to **General → Shortcut Behavior**.
